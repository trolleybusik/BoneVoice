BONE VOICE — Discord
1. Install VB-CABLE.
2. Build the EXE with the included GitHub Actions workflow (Windows build).
3. Run BoneVoice.exe.
4. Select your real microphone.
5. Select "CABLE Input" as VB-CABLE output.
6. In Discord: Settings -> Voice & Video -> Input Device -> "CABLE Output".
7. Start BoneVoice.
Your original microphone signal is NOT sent to the output; only generated bone sounds are sent.
